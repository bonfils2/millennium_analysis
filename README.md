# millennium_analysis
Code to perform a multivariate fingerprinting analysis over the past millennium using Earth System model outputs
10.xxxx/zenodo.1xxx [![DOI](https://zenodo.org/badge/xx.svg)]
 
## Description
A Jupyter notebook is provided that performs the analysis of [Kang*, Bonfils* et al. (2026)](https://xxx). Figures are generated in the notebook.
 
## Packages Needed
----------
- [xcdat](https://xcdat.readthedocs.io/en/stable/)
- xarray
- numpy
- genutil
- time
- os
- sys
- Eof
- MultivariateEof
- scipy
- matplotlib<br>
...all of which are in can be installed via conda:
```
conda create -n <ENV_NAME> -c conda-forge xcdat xesmf xarray numpy genutil matplotlib etc...
conda activate <ENV_NAME>
```
